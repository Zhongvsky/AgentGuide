    参考骨架（自己敲一遍，别复制）：

    from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class ChatRequest(BaseModel):
    question: str
    history: list[str] = []

@app.get("/")
def hello():
    return {"msg": "hello agent"}

@app.post("/chat")
async def chat(req: ChatRequest):
    # Day 2 接 LangChain，今天先 mock
    return {"answer": f"收到问题：{req.question}", "turns": len(req.history)}

    三个必须弄懂的点（说得出即算过）： - 路径参数 vs 查询参数：函数参数名和 {} 占位符一致 → 路径参数；否则自动变查询参数（?q=x&limit=3） - Pydantic 模型当参数类型 → 自动从 JSON body 解析 + 校验，失败返回 422 - I/O 密集接口一律 async def，这是第 4 周异步优化的伏笔

    验收标准

    打开 http://127.0.0.1:8000/docs 能成功调用 /chat；故意把 question 传成数字时返回 422 而不是 500——说明 Pydantic 校验生效了。
